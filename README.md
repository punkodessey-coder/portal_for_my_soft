# My Portal

Персональная стартовая страница в минималистичном glassmorphism-стиле.

## Запуск
Откройте `index.html` в браузере — установка зависимостей не требуется.

## Возможности
- Добавление, редактирование и удаление ссылок на приложения.
- Категории и поиск.
- Часы и дата.
- Импорт/экспорт приложений в JSON.
- Сохранение списка в localStorage текущего браузера.

Важно: список хранится отдельно в каждом браузере и на каждом устройстве. Используйте экспорт/импорт для переноса данных.
